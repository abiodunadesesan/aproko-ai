# Safari Web Extension Listing Draft — Aproko Live Context

Safari distribution uses an Apple wrapper workflow.

## Product name
Aproko Live Context

## Description
Ask Aproko about the page you’re reading with cursor focus, Capture tab, and Alt/Option-click solve for faster learning support.

## Privacy
See `https://aprokoai.vercel.app/privacy` (final production URL).

## Notes for App Review
- Full-page scraping happens only on user actions: “Capture tab” and Alt/Option-click solve.
- Cursor hover focus can be disabled by the user in extension settings.
- Sensitive lines are redacted before sending to Aproko services.
